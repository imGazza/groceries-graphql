# groceries-graphql

This repo contains a simple demo application built with:

* .NET Backend
* MongoDB
* GraphQL
* React Frontend

The purposes of this application are limited to learn and explore technologies and stacks I was not confident with. Therefore, many basic features are missing and were not implemented to leave space to the topics I wanted to focus on. 

What's missing:

* Even basic error handling strategies
* Complex and roles-based authorization
* Fully responsive Frontend
* Data validation
